# Security Policy

## Security Maintainer

**Shengqinchu** ([@Shengqinchu](https://github.com/Shengqinchu)) — security maintainer for this fork.

## Reporting a Vulnerability

If you discover a security issue related to this audit or the findings documented here, please contact:

- **Email:** chus25@mcmaster.ca
- **Response time:** Reports acknowledged within 48 hours.

Do **not** open a public issue for sensitive disclosures.

## Scope

This repository contains static security analysis of the 国家网络身份认证 (National Network Identity Authentication) Android application. Security reports cover cryptographic implementation, key management, and code protection findings.
